# Week 10 procedure — request validation and exceptions

1. Parse requested units inside a validation method.
2. Reject a non-numeric submission.
3. Reject an out-of-range request before inventory lookup.
4. Continue to process the remaining sample requests after each error.

Compile and run with `javac BloodWeek10.java` followed by `java BloodWeek10`.

> This is an academic same-group inventory simulation, not clinical matching guidance.
