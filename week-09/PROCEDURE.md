# Week 9 procedure — donor and inventory objects

1. Model a donor with ID, name and declared group.
2. Keep the donor array and count inside a donor registry object.
3. Register two donor objects using a registry method.
4. Search the registry for a same-group demonstration match.
5. Print the resulting object-driven summary.

Compile and run with `javac BloodWeek09.java` followed by `java BloodWeek09`.

> This is an academic same-group inventory simulation, not clinical matching guidance.
