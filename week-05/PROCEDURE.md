# Week 5 procedure — reusable inventory methods

1. Create a method that determines whether an issue can proceed.
2. Create a method that calculates remaining units after an approved issue.
3. Create a method that labels low stock.
4. Run both an approved and a held request through the methods.

Compile and run with `javac BloodWeek05.java` followed by `java BloodWeek05`.

> This is an academic same-group inventory simulation, not clinical matching guidance.
