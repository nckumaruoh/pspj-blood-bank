# Week 4 procedure — loop-driven inventory session

1. Show the core inventory-session menu.
2. Store two same-group issue requests and their available units.
3. Process the requests using a `while` loop.
4. Approve a request only when its quantity is available.
5. Print the remaining units after each request.

Compile and run with `javac BloodWeek04.java` followed by `java BloodWeek04`.

> This is an academic same-group inventory simulation, not clinical matching guidance.
