# Week 6 procedure — stock arrays and lookup

1. Store sample group labels and their unit counts in parallel arrays.
2. Search the group array for a requested label.
3. Scan the quantity array for the highest available stock.
4. Print the lookup result and top-stock group.

Compile and run with `javac BloodWeek06.java` followed by `java BloodWeek06`.

> This is an academic same-group inventory simulation, not clinical matching guidance.
