# Week 12 procedure — final collections and streams release

1. Add initial units to a linked inventory map.
2. Process one approved and one rejected same-group issue request.
3. Print the remaining group stock in insertion order.
4. Use a stream to identify low-stock groups.
5. Present the final teaching-demo report.

Compile and run with `javac BloodBank.java` followed by `java BloodBank`.

> This is an academic same-group inventory simulation, not clinical matching guidance.
