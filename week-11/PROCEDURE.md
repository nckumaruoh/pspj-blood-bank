# Week 11 procedure — inventory persistence

1. Create a CSV header and three sample inventory rows.
2. Save the data as `blood-inventory.csv`.
3. Reload the saved records.
4. Parse and sum the unit column from the restored rows.
5. Print the reloaded group count and total.

Compile and run with `javac BloodWeek11.java` followed by `java BloodWeek11`.

> This is an academic same-group inventory simulation, not clinical matching guidance.
