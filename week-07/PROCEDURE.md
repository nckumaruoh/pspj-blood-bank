# Week 7 procedure — modular inventory desk and edge cases

1. Encapsulate group stock in an inventory-desk object.
2. Add units only when the amount is positive.
3. Issue units only when requested stock is available.
4. Reject a zero-unit request without changing stock.
5. Print the final inventory status.

Compile and run with `javac BloodWeek07.java` followed by `java BloodWeek07`.

> This is an academic same-group inventory simulation, not clinical matching guidance.
